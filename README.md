# Hangman AI

An interactive web version of the Hangman AI project, redesigned for deployment on Vercel.

## Features
- Category-based word selection
- AI-assisted letter suggestions
- Greedy frequency-based guessing
- Lives and game-state management
- Responsive web interface

## Deploy on Vercel
1. Push this repository to GitHub.
2. Import the repository into Vercel.
3. Deploy with the default settings.
4. Vercel serves the static web application from the `web/` directory.

No Python runtime or environment variables are required for the Vercel version.

## Local testing
Open `web/index.html` in a browser, or serve the repository with any static HTTP server.
